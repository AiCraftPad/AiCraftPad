## Featured software

### [CircuitForge AI](https://github.com/AiCraftPad/circuitforge-ai)

A local-first Windows workspace for electronics projects. Start from a template, plan boards and wiring, review power and connection checks, and generate editable starter firmware. The current release is **1.5.0 beta**. Read the [product guide](https://aicraftpad.com/circuitforge-ai/) or download the [verified Windows release](https://github.com/AiCraftPad/circuitforge-ai/releases).

CircuitForge AI is a planning aid. Electrical checks and generated code must be reviewed and tested on the actual hardware.
